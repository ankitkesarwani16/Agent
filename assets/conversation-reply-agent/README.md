# Conversation Reply Agent

An AI agent that reads incoming conversations and generates contextually appropriate, intelligent replies in real time using SAP AI Core.

## Overview

Uses A2A Protocol, LangGraph, LiteLLM, and SAP Cloud SDK.

## Structure

- `app/main.py` - A2A server entry
- `app/agent_executor.py` - Request handling
- `app/agent.py` - Agent logic
